## Free Launch-Week Prep Tools

These are free browser tools for the **November 19, 2026** PS5 / Xbox Series X|S launch. They don't provide game files or early access.

- [GTA VI download-time calculator](https://launchready-gaming.philipairlind.chatgpt.site/download-calculator/?utm_source=github&utm_medium=referral&utm_campaign=awesome_gta6_launchweek) — Estimate a download window using your own connection speed and a user-chosen file size; actual times vary.
- [Console storage checker](https://launchready-gaming.philipairlind.chatgpt.site/tools/storage-space-checker/?utm_source=github&utm_medium=referral&utm_campaign=awesome_gta6_launchweek) — Estimate how much available space to free, without presenting unverified install sizes as final.
- [My Play Desk](https://launchready-gaming.philipairlind.chatgpt.site/play-desk/?utm_source=github&utm_medium=referral&utm_campaign=awesome_gta6_launchweek) — A local-first, spoiler-conscious session planner for goals, notes and checklists.
- [Region release clock](https://launchready-gaming.philipairlind.chatgpt.site/tools/region-release-clock/?utm_source=github&utm_medium=referral&utm_campaign=awesome_gta6_launchweek) — Check regional unlock times alongside official Rockstar support guidance.

All four tools are part of **LaunchReady Gaming**, an independent project run by this list's maintainer. They are not affiliated with Rockstar Games or Take-Two Interactive. The tools are optional; feedback and alternative suggestions are welcome.
